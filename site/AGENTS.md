# groundwork docs site

`site/` is the Nextra documentation site for the groundwork plugin, not a standalone project.
Read the repository-root `CLAUDE.md` and `README.md` before working here — they carry the plugin
conventions, and the README documents the `/groundwork` base path, local preview, and how the site
reaches GitHub Pages.

The block below is generated by `next dev` when it detects an agent session
(`node_modules/next/dist/server/lib/generate-agent-files.js`). Next.js offers no way to turn it off,
so it is committed deliberately. Only the text between its markers is rewritten — this section is
preserved.
